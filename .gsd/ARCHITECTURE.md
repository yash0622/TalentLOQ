## Data Flow

1. **User Authentication:**
   - Flutter App collects credentials → Sends request via Dio to FastAPI `/auth/login`.
   - FastAPI verifies hash in MongoDB → Issues JWT access & refresh tokens.
   - Flutter stores tokens securely using `flutter_secure_storage`.
2. **Authenticated Requests:**
   - Flutter sends requests with `Authorization: Bearer <token>`.
   - FastAPI `dependencies.py` extracts & validates JWT token, retrieving active user context.
